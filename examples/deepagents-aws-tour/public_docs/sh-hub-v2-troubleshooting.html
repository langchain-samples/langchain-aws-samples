SmartHome Hub V2 WiFi troubleshooting

For SmartHome Hub V2 devices that drop WiFi after setup, first confirm the hub is on firmware v2.1.5 or newer.

If the hub is on firmware v2.1.4, reboot it by unplugging power for 30 seconds, open the SmartHome app on the same WiFi network, and accept the firmware update prompt.

After the update, the LED should turn solid green and the app should show firmware v2.1.5 under Settings, Device, SmartHome Hub, About.

If WiFi still drops after v2.1.5, collect router security mode and signal-strength details before escalating.
