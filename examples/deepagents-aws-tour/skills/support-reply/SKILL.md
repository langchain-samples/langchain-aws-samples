# Support reply skill

## Overview

A repeatable format for the customer-facing reply, so every response lands the same way regardless of which model or sub-agent drafts it.

## When to use

When composing the final reply to a customer ticket, once the research findings are in hand.

## Structure

1. **One-line acknowledgment** - name the problem and the order, showing you read the ticket. One sentence.
2. **The fix** - the specific documented fix (firmware version + steps), or, if none exists, the best next step and what you're doing about it.
3. **Close** - what happens next (e.g., "reply here if it persists and we'll escalate"). No sign-off boilerplate.

## Rules

- Under 150 words.
- No forbidden phrases: "we apologize for any inconvenience", "thank you for your patience", "we value your business".
- Cite the fix exactly as the knowledge base states it - don't paraphrase a version number.
